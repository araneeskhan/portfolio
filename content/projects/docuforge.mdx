DocuForge standardizes messy documents — raw text, legacy DOC, inconsistent DOCX — into publication-ready DOCX and PDF exports. The formatting is deterministic by design: a rule set handles heading hierarchy, typography, spacing, smart quotes, and justification, so the same input always produces the same output and nothing is rewritten without an explicit rule. Nothing leaves the machine and there is no model API in the path, which makes it usable on documents that cannot be sent to a third party. A FastAPI backend separates parsing, formatting, and export behind a React and TypeScript client.
