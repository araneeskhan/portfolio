A mobile strategy game set in a cyberpunk city, where the player builds a criminal organization from street level upward. Progress compounds: missions and territory pay for businesses, businesses generate income while the player is away, and that income funds recruitment and upgrades for the next tier of both. Built in React Native with Zustand for game state and Firebase for persistence.
