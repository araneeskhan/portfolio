A web workspace that collects several assistive developer tools behind one navigation shell instead of leaving them as separate tabs: an OpenAI-backed code assistant for suggestions and pair programming, a resume analyzer, a shared community space, progress analytics, and connectors for external developer tools. Built as a React single-page app with Chakra UI and Framer Motion, over a Node service that brokers model calls.
