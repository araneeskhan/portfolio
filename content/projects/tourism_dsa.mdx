A console travel booking and management system written in C++ without a database or framework, where each requirement is met by choosing the right data structure. Routing between cities runs on Dijkstra's algorithm; user profiles and their receipts are held as nested linked lists; cancellations are processed FIFO through a queue with explicit reclamation; and state survives between sessions through a serialization layer written by hand, which is the difficult part — the records are pointer-based, so saving them means flattening a linked structure to text and rebuilding the links on load. Memory is managed manually with explicit teardown on every deletion path.
