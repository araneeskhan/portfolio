A summarization tool delivered on both web and mobile, built to shorten long articles and documents without the user retyping them. Hugging Face Transformer models produce abstractive summaries rather than extracted sentences; an OpenCV OCR pipeline pulls text out of photographed or scanned pages so printed material can be summarised directly; and the Google Cloud Translation API extends it past English. Summaries are stored in a Firebase-backed document system where they can be edited, formatted, archived, and exported to PDF or DOCX. The mobile client is Flutter, the web client Bootstrap, over a shared Python service.
